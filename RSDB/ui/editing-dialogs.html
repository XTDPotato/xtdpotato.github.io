更新日志
基础操作
  • 添加/编辑：右下 + 按钮，或点击表格行快速编辑
  • 单元格直编：点击表格单元格，修改内容与格式，右上角保存或取消
  • 批量删除：右上 ⋮ → 开启多选模式 → 勾选删除 → 底部批量删除
数据处理
  • 导入导出：抽屉菜单 → 一键导入/导出 Excel 表格
  • 全局搜索：顶部搜索框，匹配项与对应整行会同步高亮
  • 搜索替换：点击顶部搜索按钮 → 打开替换面板，支持单条/全部替换
  • 重量计算：抽屉菜单 → 计算重量 → 自动填充单支/总重数据
  • 数据排序：抽屉菜单 → 数据排序 → 自定义规则一键应用
行序移动 【核心功能】
  • 电脑端：表格首列 ↑↓ 按钮，单击 = 上/下移一行
  • 点击表格首列的移动按钮，在弹窗中选择目标项目及其上方或下方
  • 手机端：表格首列 ↑↓ 按钮，轻触 = 上/下移一行
  • 勾选多个项目可保持原顺序批量移动，支持搜索和分页
  • 移动兼容：支持分页/搜索过滤，移动后自动跳转对应页码，行序永久保存
手势与显示适配
  • 表格缩放：手机双指捏合/张开，自由缩放且表头保持冻结
  • 适配显示：自动兼容电脑/手机屏幕，表格自适应排版无遮挡
虚拟键盘 【快捷录入】
  • 自动唤出：点击编辑框/编辑按钮进入输入状态，虚拟键盘自动弹出
  • 自动定位：键盘弹出时自动滚动到当前编辑框，避免被遮挡
  • 光标重置：切换/点击字段后，光标默认定位到内容末尾，继续追加输入
  • 光标同步：窗口/弹窗打开、滚动、尺寸变化后延迟刷新光标位置，避免错位
  • 字段跳转：轻触右下 ▼ 键，跳转下一个输入项并自动定位
  • 关闭方式：按住右下 ▼ 键向上滑动后松开 = 关闭虚拟键盘（会显示“关闭”提示）
  • 快编模式：右下键显示 ✔，轻触即可关闭虚拟键盘
  • 删除键：按住 ← 连续删除；向上滑动后松开可清空，超过 50 个字符会先确认
  • 输入法：中英文、拼音与分词位于快捷工具栏；拼音/英文在上层，待选词在下层，鼠标滚轮可平滑翻页
  • 智能建议：当某字段值或前缀累计出现达到阈值，显示“+ 值/前缀”；点击输入到编辑框，长按添加为快捷短语
  • 模糊匹配：输入如“25D0”，会智能建议此前频繁使用的“25D0”前缀
  • 开关控制：设置 → 智能建议可控制建议与 inputStats 记录，也可按字段调整
  • 字符滑动：部分字符键支持“轻触输入字母/数字，向上滑动松开输入符号”
桌面模式
  • 桌面端默认使用系统键盘，不自动弹出虚拟键盘
  • 快捷短语显示在页面底部，工具栏可长按拖动；拖动时左右晃动可循环完整、加号和输入导航布局
  • 设置 → 快捷短语 → 桌面模式，可随时开启或关闭
  • 设置 → 编辑框键盘模式（按字段）可以覆盖桌面模式的默认键盘
